# eda-v-tochku.ru

Лендинг «Еда в точку»: умный холодильник со свежей едой в офис (Тольятти). Бренд временный, названий и знаков ReFresh на странице нет. Статический сайт: `index.html`, `landing.css`, без сборки и серверного кода.

Источник правды по содержанию и плану — `docs/LANDING_PLAN.md` в репозитории портала `fridge-analizer.orgbox.net`. До публикации в странице остаются жёлтые пометки «Уточнить» (условия для компании, способ оплаты, реквизиты), форма заявки пока не отправляет данные, `robots.txt` закрывает сайт от индексации, в `<head>` стоит `noindex`.

## Публикация

- Домен: `eda-v-tochku.ru` (файл `CNAME` для GitHub Pages).
- Перед открытием сайта: убрать пометки «Уточнить», подключить форму заявок, удалить `Disallow: /` из `robots.txt` и `noindex` из `index.html`, добавить политику конфиденциальности.

## Правила работы

- Изменения — в ветках `landing/<задача>` и через PR; сливает в `main` владелец.
- Секреты и персональные данные в репозиторий не коммитить.
- Структура на сервере: репозиторий лежит в `~/eda-v-tochku.ru`, а веб-корень сайта — `~/eda-v-tochku.ru/public_html`. После обновления репозитория деплой копирует `index.html`, `landing.css`, `favicon.png`, `robots.txt` и папку `images/` в `public_html` (папку можно переопределить секретом `PUBLISH_DIR`).

## Форма заявки

Форма отправляет данные в `submit.php` (нужен PHP с расширением curl). Заявка пишется в `leads.csv` и уходит в группу MAX. Если MAX недоступен, заявка всё равно остаётся в файле, ошибка пишется в `errors.log`.

Данные лежат вне веб-корня, в `~/eda-v-tochku.ru/.leads/` (папка в `.gitignore`):
- `leads.csv` — заявки (UTF-8, разделитель `;`, открывается в Excel);
- `errors.log` — ошибки отправки;
- `config.php` — настройки, создаётся вручную на сервере и в Git не попадает:

```php
<?php
return [
    'max_token'   => 'ТОКЕН_БОТА',
    'max_chat_id' => 'ID_ГРУППЫ',
    // 'max_api_base' => 'https://platform-api2.max.ru',
    // 'ca_bundle'    => '/путь/к/сертификату.pem', // если хостинг не доверяет сертификату Минцифры
];
```

Отправить в группу по названию нельзя, нужен `chat_id`. Узнать его: добавить бота в группу и запустить `php tools/max-chat-id.php ТОКЕН_БОТА`, затем написать в группе любое сообщение.
