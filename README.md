# eda-v-tochku.ru

Лендинг «Еда в точку»: умный холодильник со свежей едой в офис (Тольятти). Бренд временный, названий и знаков ReFresh на странице нет. Статический сайт без сборки: `index.html`, `landing.css`, `images/`; единственный серверный файл — `submit.php` (приём заявок).

Текущее состояние, решения и список задач — `docs/HANDOFF.md`; правила для Claude — `CLAUDE.md`. Исходный план содержания — `docs/LANDING_PLAN.md` в репозитории портала `fridge-analizer.orgbox.net`. До публикации в странице остаются жёлтые пометки «Уточнить» (условия для компании, способ оплаты, реквизиты), форма заявки работает через `submit.php` (см. ниже), `robots.txt` закрывает сайт от индексации, в `<head>` стоит `noindex`.

## Публикация

- Домен: `eda-v-tochku.ru` (файл `CNAME` для GitHub Pages).
- Перед открытием сайта: убрать пометки «Уточнить», добавить в форму ссылку на политику конфиденциальности, удалить `Disallow: /` из `robots.txt` и `noindex` из `index.html`, добавить политику конфиденциальности.

## Правила работы

- Изменения — в ветках `landing/<задача>` и через PR; сливает в `main` владелец.
- Секреты и персональные данные в репозиторий не коммитить.
- Структура на сервере: репозиторий лежит в `~/eda-v-tochku.ru`, а веб-корень сайта — `~/eda-v-tochku.ru/public_html`. После обновления репозитория деплой копирует `index.html`, `landing.css`, `favicon.png`, `robots.txt`, `submit.php` и папку `images/` в `public_html` (папку можно переопределить секретом `PUBLISH_DIR`).

## Форма заявки

Форма отправляет данные в `submit.php` (нужен PHP с расширением curl). Заявка пишется в `leads.csv` и уходит в группу MAX. Если MAX недоступен, заявка всё равно остаётся в файле, ошибка пишется в `errors.log`.

Данные лежат вне веб-корня, в `~/eda-v-tochku.ru/.leads/` (папка в `.gitignore`):
- `leads.csv` — заявки (UTF-8, разделитель `;`, открывается в Excel);
- `errors.log` — ошибки отправки.

Настройки хранятся в `.env` в корне проекта (`~/eda-v-tochku.ru/.env`, вне веб-корня, в Git не попадает). Образец — `.env.example`:

```
MAX_BOT_TOKEN=токен_бота
MAX_CHAT_ID=id_группы
# MAX_API_BASE=https://platform-api2.max.ru
# MAX_CA_BUNDLE=/путь/к/сертификату.pem   # если хостинг не доверяет сертификату Минцифры
# LEADS_DIR=                              # по умолчанию ../.leads
```

Отправить в группу по названию нельзя, нужен `chat_id`. Узнать его: добавить бота в группу и запустить `php tools/max-chat-id.php` (токен берётся из `.env`, можно передать аргументом), затем написать в группе любое сообщение.
