# Инструкции для Claude: лендинг «Еда в точку»

Полный контекст и текущее состояние — в `docs/HANDOFF.md`. Прочитай его перед работой.

## Правила
- Отвечать по-русски, коротко и по делу.
- Рабочая ветка — `main`, она деплоится автоматически на боевой сервер. Ветка по умолчанию на GitHub может быть `landing/standalone` (устаревшая): работать от `main`.
- Изменения — в ветках `landing/<задача>`; в `main` сливает владелец или Claude по прямой просьбе владельца («слей»). Каждый пуш в `main` запускает деплой на сервер, после слияния проверять результат в GitHub Actions.
- Не публиковать на сайте личные телефоны и Telegram сотрудников, секреты и токены. Секреты только в `.env` на сервере (в Git не попадает).
- Бренд временный. Названий и знаков ReFresh / REFRESHTECH на сайте и в картинках быть не должно.
- Домен — `eda-v-tochku.ru` (не `еда.ру`).
- Перед слиянием: проверить `index.html` теми же проверками, что в `.github/workflows/ci.yml`, и посмотреть скриншоты 1440 и 390 px.
- Клон в облачной сессии мелкий и single-branch: стоп-хук может ложно сообщать о «непушенных коммитах», см. «Подводные камни» в `docs/HANDOFF.md`.
