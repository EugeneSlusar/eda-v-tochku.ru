# Промпты для ChatGPT — 16 фотографий (стиль v4)

Как работать: открыть **один новый чат** в ChatGPT (с генерацией картинок), отправить «Сообщение 0», затем присылать промпты 1–16 **по одному, по одному в сообщении**. Каждый результат сохранять как PNG под именем из заголовка и класть в `design/originals/` (или прислать Claude в чат).

Формат файла: `hero` — вертикальный (1024×1536), все остальные — горизонтальные (1536×1024). Важные объекты держите ближе к центру: края обрежутся.

## Сообщение 0 (отправить первым)

```

2. Фотореализм: коммерческая фуд- и интерьерная съёмка, естественный дневной свет, малая глубина резкости, аппетитная свежая еда.
3. Палитра: тёплые оранжевые акценты (#f97316) на белом и светло-сером; светлые современные интерьеры.
4. На картинках НЕТ никакого текста: ни букв, ни цифр, ни логотипов, ни вывесок, ни этикеток с надписями, ни водяных знаков, ни брендов. Если на упаковке что-то должно быть — только однотонные этикетки без текста.
5. Один и тот же холодильник во всех сценах, где он есть: высокий узкий, до потолка не доходит (около 2 м), матово-тёмно-графитовый корпус, стеклянная дверь во всю высоту, тёплая белая подсветка полок, на правом ребре корпуса вертикальная оранжевая полоса (#f97316); на ней только простые значки без текста. На самом холодильнике надписей нет.
6. Люди: естественные, разные, без позирования в камеру, лица не крупным планом без необходимости. Руки с нормальным числом пальцев.
```

## Если ChatGPT всё равно выдаёт «графику»
Отправьте: «Это не то. Мне нужна одна реалистичная фотография, как снимок фотокамерой: не инфографика, не макет сайта, не иллюстрация, не набор карточек. Только сцена из промпта, без текста. Сгенерируй заново.» Если он снова рисует лендинг целиком — начните новый чат и повторите Сообщение 0.
