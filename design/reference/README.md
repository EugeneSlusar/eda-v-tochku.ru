# Референсы для генерации картинок

Только для ориентира при генерации, на сайт не попадают (`design/` не деплоится). На референсах есть чужие бренды (Pepsi, Lipton, Lay's и др.): **на готовых картинках их быть не должно**, надписи и логотипы убираются.

- `style-reference.webp` — общий стиль лендинга (оранжево-белый, фотореализм).
- `fridge-cooler-reference.png` — реальная форма холодильника (Pepsi-кулер): высокий шкаф, одна стеклянная дверь во всю высоту, светящийся короб сверху, боковая панель, чёрное основание с вентиляционной решёткой. У нас панель и короб оранжевые (#f97316), без логотипов.
- `fridge-loading-reference.webp` — как выглядит реальная загрузка: многоярусные полки с планками-ценниками, сэндвичи в упаковках, контейнеры с этикетками, корзинка со снеками, напитки на нижних полках, подсветка по краю двери. Продукты у нас свои (салаты, обеды), этикетки пустые.
- `logo-current.png` — текущий временный логотип «Еда в точку» (оранжевая капля-метка с вилкой и ложкой + надпись и подпись «Готовая еда рядом»). Исходник для перерисовки в двух вариантах (сайт и лайтбокс холодильника).
